# E13.4 — Repos = repos — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un jour de repos s'affiche partout (briefing, `/today`, `/plan`) comme un vrai repos : pas de structure de séance, pas de bouton d'action de séance, pas de compte rendu de readiness, et plus de « Bonne séance ! ».

**Architecture:** Trois changements ciblés sur des fichiers existants, aucune migration, aucune nouvelle route, aucune nouvelle donnée. On exploite le type `rest` (planned session) et le flag `is_rest_day` déjà produits par le worker. (1) `format_explanation_md` (worker) devient conscient du repos. (2) `SessionCard` (front) gagne une variante repos sobre. (3) `BriefingCard` (front) masque badge readiness et revue d'activités au repos.

**Tech Stack:** Python 3.12, FastAPI, pytest, ruff, mypy (worker) ; Next.js 15, TypeScript, React, Vitest + Testing Library (frontend).

## Global Constraints

- Worker : Python 3.12 ; `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy src/` doivent passer ; tests `uv run pytest`. Commandes exécutées depuis `worker/`.
- Frontend : pas d'emoji dans l'UI (utiliser des icônes Lucide) ; tests Vitest dans `tests/unit/**/*.test.tsx` avec en-tête `// @vitest-environment jsdom`. Commandes exécutées depuis la racine repo.
- Conventional Commits stricts (`feat:`, `test:`, `refactor:`…), body lines ≤ 100 chars.
- Un jour de repos est identifié par `session_type === 'rest'` (ou `sport === 'rest'`) côté front, et `is_rest_day` côté briefing.
- Non-régression : le comportement hors repos doit rester strictement inchangé.

```python
def format_explanation_md(
    factors: list[ReadinessFactor], status: Status, is_rest_day: bool = False
) -> str:
    """Build a short FR markdown explanation from the factors."""
    negatives = [f for f in factors if f.impact < 0]
    if not negatives:
        if is_rest_day:
            return (
                "Tous les signaux sont au vert. Profite de cette journée de repos "
                "pour bien récupérer."
            )
        if status == "ready":
            return "Tous les signaux sont bons. Bonne séance !"
        return "Conditions correctes mais pas de données récentes pour affiner."
    if is_rest_day:
        head = "Jour de repos, avec quelques signes de fatigue à surveiller :"
    else:
        head = {
            "ready": "Légers signaux à surveiller :",
            "caution": "Quelques signes de fatigue :",
            "rest_advised": "Signes de fatigue marqués :",
        }[status]
    bullets = "\n".join(f"- {f.explanation}" for f in negatives)
    return f"{head}\n\n{bullets}"
```
