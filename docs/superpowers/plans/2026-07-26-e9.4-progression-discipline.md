# E9.4 — Progression par discipline — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Détecter par discipline si l'athlète progresse, stagne, régresse ou n'assimile pas sa charge, l'afficher sur `/stats` et le brancher sur la décision coach du briefing.

**Architecture:** Un module Python pur calcule un facteur d'efficacité (vitesse ajustée à la pente ÷ FC) par activité, puis compare la médiane des 28 derniers jours à celle des 62 précédents. Le résultat est matérialisé dans une table `discipline_progress` (une ligne par user, une colonne `jsonb` par discipline) au recompute post-sync, exactement comme `recovery_baselines` de E9.3. Le briefing et `/stats` lisent cette table — un seul calcul, deux consommateurs.

**Tech Stack:** Python 3.12 (worker FastAPI, pytest, ruff, mypy strict), Supabase Postgres + RLS, Next.js 15 App Router / TypeScript strict, Vitest.

**Spec:** `docs/superpowers/specs/2026-07-26-e9.4-progression-discipline-design.md`

## Global Constraints

- **Décision non tranchée par l'owner, défauts de la spec appliqués** : seuils ±3 % d'EF, 5 bpm de FC médiane, 4 activités minimum, 6 pour la confiance haute, fenêtre récente 28 j. À réviser à l'usage.
- Toutes les constantes de seuil vivent groupées en tête de `discipline_progress.py`. Aucune valeur magique dispersée dans le code.
- Le module de calcul est **pur** : aucun accès DB en dehors de `recompute_discipline_progress`.

- Aucune tendance annoncée sous le seuil d'échantillon : `insufficient_data` est une sortie légitime.
- Aucune métrique isolée ne fait verdict : la décision coach croise toujours efficacité **et** charge.
- Langage prudent côté UI, jamais de diagnostic. **Aucun emoji** dans `app/` ni `components/` — la CI échoue (`grep -rP "[\x{1F300}-\x{1F9FF}\x{2600}-\x{27BF}]" app/ components/`). Icônes Lucide uniquement.

```python
"""Progression par discipline (E9.4).

Calcule un facteur d'efficacité par activité — vitesse ajustée à la pente divisée
par la FC moyenne, soit « combien d'avance par battement de cœur » — puis compare la
médiane des 28 derniers jours à celle des 62 précédents.

L'athlète n'a pas de capteur de puissance (0 activité vélo sur 29 en porte une) et
`fc_max_bpm` est NULL, donc ni la puissance ni un filtre d'intensité en pourcentage
de FC max ne sont utilisables. Voir la spec pour le détail de l'inventaire.

Les seuils ci-dessous sont des premières estimations à réviser à l'usage, pas des
valeurs issues de la littérature.
"""

from __future__ import annotations

from datetime import date, datetime
from typing import Any

CORE_DISCIPLINES = ("run", "bike", "swim")

# Durée minimale pour qu'une activité soit comparable. Plus court, l'échauffement et
# les arrêts pèsent trop sur la moyenne de FC.
MIN_DURATION_S = {"run": 1200, "bike": 1200, "swim": 900}

# Équivalent plat d'un mètre de D+ : monter 1 m coûte à peu près l'énergie de 8 m de
# plat en course. Le bassin est plat, donc 0 en natation.
GRADE_EQUIV_M_PER_M = {"run": 8.0, "bike": 5.0, "swim": 0.0}


def _as_float(value: Any) -> float | None:
    if value is None:
        return None
    try:
        return float(value)
    except (TypeError, ValueError):
        return None


def _activity_date(row: dict[str, Any]) -> date | None:
    raw = row.get("start_time")
    if not isinstance(raw, str):
        return None
    try:
        return datetime.fromisoformat(raw).date()
    except ValueError:
        return None


def is_eligible(row: dict[str, Any]) -> bool:
    """True quand l'activité peut entrer dans une comparaison d'efficacité."""
    sport = row.get("sport")
    if sport not in CORE_DISCIPLINES:
        return False
    hr = _as_float(row.get("hr_avg"))
    if not hr:
        return False
    distance = _as_float(row.get("distance_m"))
    if not distance or distance <= 0:
        return False
    duration = _as_float(row.get("duration_s"))
    if not duration or duration < MIN_DURATION_S[sport]:
        return False
    return True


def activity_ef(row: dict[str, Any]) -> float | None:
    """Facteur d'efficacité : vitesse ajustée à la pente / FC moyenne. None si indécidable."""
    sport = row.get("sport")
    if sport not in CORE_DISCIPLINES:
        return None
    hr = _as_float(row.get("hr_avg"))
    distance = _as_float(row.get("distance_m"))
    duration = _as_float(row.get("duration_s"))
    if not hr or not distance or not duration:
        return None
    elevation = _as_float(row.get("elevation_gain_m")) or 0.0
    equiv_distance = distance + GRADE_EQUIV_M_PER_M[sport] * elevation
    return (equiv_distance / duration) / hr
```

```python
TODAY = date(2026, 7, 26)


def _activity(days_ago: int, *, sport: str = "run", distance_m: float = 10000, hr: int = 150) -> dict[str, object]:
    when = TODAY - timedelta(days=days_ago)
    return {
        "sport": sport,
        "start_time": f"{when.isoformat()}T06:00:00+00:00",
        "duration_s": 3600,
        "distance_m": distance_m,
        "elevation_gain_m": 0,
        "hr_avg": hr,

REFERENCE_DAYS = [32, 40, 48, 56, 64, 72]
```

```python
WINDOW_DAYS = 90
RECENT_DAYS = 28
DELTA_THRESHOLD_PCT = 3.0
HR_MEDIAN_GUARD_BPM = 5.0
ELEVATION_GUARD_M_PER_KM = 15.0
CTL_RISE_THRESHOLD_PCT = 5.0
MIN_ACTIVITIES = 4
CONFIDENCE_HIGH_ACTIVITIES = 6

State = Literal["progressing", "stable", "declining", "load_not_absorbed", "insufficient_data"]
Confidence = Literal["high", "low", "none"]


class DisciplineProgress(TypedDict):
    state: State
    delta_pct: float | None
    ef_recent: float | None
    ef_reference: float | None
    n_recent: int
    n_reference: int
    hr_median_recent: int | None
    hr_median_reference: int | None
    confidence: Confidence
    limiting_factors: list[str]
    excluded_count: int
    window_recent_days: int
    window_reference_days: int


def _empty_progress() -> DisciplineProgress:
    return {
        "state": "insufficient_data",
        "delta_pct": None,
        "ef_recent": None,
        "ef_reference": None,
        "n_recent": 0,
        "n_reference": 0,
        "hr_median_recent": None,
        "hr_median_reference": None,
        "confidence": "none",
        "limiting_factors": [],
        "excluded_count": 0,
        "window_recent_days": RECENT_DAYS,
        "window_reference_days": WINDOW_DAYS - RECENT_DAYS,
    }


def _elevation_per_km(rows: list[dict[str, Any]]) -> float | None:
    ratios = []
    for row in rows:
        distance = _as_float(row.get("distance_m"))
        if not distance:
            continue
        elevation = _as_float(row.get("elevation_gain_m")) or 0.0
        ratios.append(elevation / (distance / 1000))
    return statistics.median(ratios) if ratios else None


def _ctl_is_rising(ctl_now: float | None, ctl_28d_ago: float | None) -> bool | None:
    """True si le CTL a monté d'au moins le seuil, None si la charge est inconnue."""
    if ctl_now is None or ctl_28d_ago is None or ctl_28d_ago <= 0:
        return None
    return (ctl_now - ctl_28d_ago) / ctl_28d_ago * 100 >= CTL_RISE_THRESHOLD_PCT


def _progress_for_discipline(
    recent: list[dict[str, Any]],
    reference: list[dict[str, Any]],
    excluded_count: int,
    *,
    ctl_now: float | None,
    ctl_28d_ago: float | None,
) -> DisciplineProgress:
    result = _empty_progress()
    result["n_recent"] = len(recent)
    result["n_reference"] = len(reference)
    result["excluded_count"] = excluded_count
    factors: list[str] = []
    if excluded_count:
        factors.append("activities_excluded")

    ef_recent_values = [ef for ef in (activity_ef(r) for r in recent) if ef is not None]
    ef_reference_values = [ef for ef in (activity_ef(r) for r in reference) if ef is not None]
    hr_recent = [hr for hr in (_as_float(r.get("hr_avg")) for r in recent) if hr]
    hr_reference = [hr for hr in (_as_float(r.get("hr_avg")) for r in reference) if hr]

    if ef_recent_values:
        result["ef_recent"] = round(statistics.median(ef_recent_values), 8)
    if ef_reference_values:
        result["ef_reference"] = round(statistics.median(ef_reference_values), 8)
    if hr_recent:
        result["hr_median_recent"] = round(statistics.median(hr_recent))
    if hr_reference:
        result["hr_median_reference"] = round(statistics.median(hr_reference))

    # Ordre 1 — échantillon insuffisant : on ne compare rien.
    if len(ef_recent_values) < MIN_ACTIVITIES or len(ef_reference_values) < MIN_ACTIVITIES:
        result["limiting_factors"] = factors
        return result

    if (
        len(ef_recent_values) < CONFIDENCE_HIGH_ACTIVITIES
        or len(ef_reference_values) < CONFIDENCE_HIGH_ACTIVITIES
    ):
        result["confidence"] = "low"
        factors.append("small_sample")
    else:
        result["confidence"] = "high"

    ef_recent = result["ef_recent"]
    ef_reference = result["ef_reference"]
    # Garanti non nul par le seuil MIN_ACTIVITIES ci-dessus, mais on garde une garde
    # explicite plutôt qu'un assert : un assert disparaît sous python -O.
    if ef_recent is None or not ef_reference:
        result["limiting_factors"] = factors
        return result
    result["delta_pct"] = round((ef_recent - ef_reference) / ef_reference * 100, 2)

    elevation_recent = _elevation_per_km(recent)
    elevation_reference = _elevation_per_km(reference)
    if (
        elevation_recent is not None
        and elevation_reference is not None
        and abs(elevation_recent - elevation_reference) > ELEVATION_GUARD_M_PER_KM
    ):
        factors.append("elevation_mix_changed")

    # Ordre 2 — mix d'intensité modifié : la comparaison n'est pas interprétable, dans
    # aucun des deux sens. Enchaîner des sorties plus faciles fait monter l'EF sans gain
    # de forme, et l'inverse fait baisser l'EF sans perte de forme.
    hr_median_recent = result["hr_median_recent"]
    hr_median_reference = result["hr_median_reference"]
    if (
        hr_median_recent is not None
        and hr_median_reference is not None
        and abs(hr_median_recent - hr_median_reference) > HR_MEDIAN_GUARD_BPM
    ):
        factors.append("intensity_mix_changed")
        result["state"] = "stable"
        result["limiting_factors"] = factors
        return result

    delta = result["delta_pct"]
    if delta <= -DELTA_THRESHOLD_PCT:
        rising = _ctl_is_rising(ctl_now, ctl_28d_ago)
        if rising is None:
            factors.append("load_unknown")
            result["state"] = "declining"
        elif rising:
            result["state"] = "load_not_absorbed"
        else:
            result["state"] = "declining"
    elif delta >= DELTA_THRESHOLD_PCT:
        result["state"] = "progressing"
    else:
        result["state"] = "stable"

    result["limiting_factors"] = factors
    return result


def compute_discipline_progress(
    activities: list[dict[str, Any]],
    *,
    today: date,
    ctl_now: float | None,
    ctl_28d_ago: float | None,
) -> dict[str, DisciplineProgress]:
    """Tendance d'efficacité par discipline. Une clé par discipline, toujours présente."""
    recent_cutoff = today - timedelta(days=RECENT_DAYS)
    window_cutoff = today - timedelta(days=WINDOW_DAYS)

    buckets: dict[str, tuple[list[dict[str, Any]], list[dict[str, Any]], int]] = {
        discipline: ([], [], 0) for discipline in CORE_DISCIPLINES
    }

    for row in activities:
        sport = row.get("sport")
        if sport not in CORE_DISCIPLINES:
            continue
        when = _activity_date(row)
        if when is None or when < window_cutoff or when > today:
            continue
        recent, reference, excluded = buckets[sport]
        if not is_eligible(row):
            buckets[sport] = (recent, reference, excluded + 1)
            continue
        if when >= recent_cutoff:
            recent.append(row)
        else:
            reference.append(row)

    return {
        discipline: _progress_for_discipline(
            recent, reference, excluded, ctl_now=ctl_now, ctl_28d_ago=ctl_28d_ago
        )
        for discipline, (recent, reference, excluded) in buckets.items()
    }
```

```ts
/**
 * E9.4 — logique d'affichage de la progression par discipline.
 *
 * Séparée du composant parce que `app/(app)/_components/**` est mesuré par le gate de
 * couverture Sonar : la logique testable vit ici, le composant reste présentationnel.
 */

export type DisciplineProgressState =
  | 'progressing'
  | 'stable'
  | 'declining'
  | 'load_not_absorbed'
  | 'insufficient_data'

export type StateTone = 'positive' | 'neutral' | 'warning' | 'unknown'

export interface DisciplineProgressEntry {
  readonly state: DisciplineProgressState
  readonly delta_pct: number | null
  readonly n_recent: number
  readonly n_reference: number
  readonly hr_median_recent: number | null
  readonly hr_median_reference: number | null
  readonly confidence: 'high' | 'low' | 'none'
  readonly limiting_factors: readonly string[]
  readonly window_recent_days: number
  readonly window_reference_days: number
}

export interface DisciplineProgressRow {
  readonly computed_at: string | null
  readonly run: DisciplineProgressEntry | null
  readonly bike: DisciplineProgressEntry | null
  readonly swim: DisciplineProgressEntry | null
}

const STALE_AFTER_MS = 48 * 60 * 60 * 1000

const STATE_LABELS: Record<DisciplineProgressState, string> = {
  progressing: 'En progression',
  stable: 'Stable',
  declining: 'En baisse',
  load_not_absorbed: 'Charge mal assimilée',
  insufficient_data: 'Pas assez de données',
}

const STATE_TONES: Record<DisciplineProgressState, StateTone> = {
  progressing: 'positive',
  stable: 'neutral',
  declining: 'warning',
  load_not_absorbed: 'warning',
  insufficient_data: 'unknown',
}

const FACTOR_LABELS: Record<string, string> = {
  intensity_mix_changed:
    "Ton intensité moyenne a changé entre les deux périodes : la comparaison n'est pas concluante.",
  elevation_mix_changed: 'Le dénivelé de tes sorties a nettement changé entre les deux périodes.',
  small_sample: 'Peu d’activités comparables sur la période.',
  activities_excluded: 'Au moins une activité a été écartée (FC absente ou séance trop courte).',
  load_unknown: 'Ta charge d’entraînement est inconnue sur la période, impossible de la croiser.',
}

const DISCIPLINE_LABELS: Record<string, string> = {
  run: 'Course',
  bike: 'Vélo',
  swim: 'Natation',
}

export function stateLabel(state: DisciplineProgressState): string {
  return STATE_LABELS[state]
}

export function stateTone(state: DisciplineProgressState): StateTone {
  return STATE_TONES[state]
}

export function formatDelta(deltaPct: number | null): string {
  if (deltaPct === null) return '—'
  const sign = deltaPct < 0 ? '-' : '+'
  return `${sign}${Math.abs(deltaPct).toFixed(1).replace('.', ',')} %`
}

export function limitingFactorLabel(factor: string): string {
  return FACTOR_LABELS[factor] ?? factor
}

export function isStale(computedAt: string | null, now: Date): boolean {
  if (!computedAt) return true
  const parsed = Date.parse(computedAt)
  if (Number.isNaN(parsed)) return true
  return now.getTime() - parsed > STALE_AFTER_MS
}

export function disciplineLabel(discipline: string): string {
  return DISCIPLINE_LABELS[discipline] ?? discipline
}
```

## Écart assumé par rapport à la spec

La spec prévoit que « les allures passent par le helper existant `formatSpeedForSport` ». Le panneau de la Task 7 n'affiche **aucune allure absolue** : la tendance est exprimée en pourcentage d'écart d'efficacité, une grandeur sans unité. `formatSpeedForSport` n'a donc rien à formater ici et n'est pas utilisé — ce n'est pas un oubli.

Raison de fond : l'EF (m/s par bpm) n'a pas de sens à afficher tel quel pour un athlète, et le convertir en allure absolue reviendrait à afficher une allure fictive « à FC constante » que l'athlète n'a jamais courue. Le pourcentage est plus honnête. Si une future itération affiche des allures réelles par fenêtre, la contrainte de la spec redevient valable et le helper doit être utilisé.
