# E9.5 — Steps comme signal contextuel du briefing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter `steps` comme 6ème signal de récupération personnel (baseline médiane 28j)
et l'utiliser comme facteur faible (-5) du `readiness_score` du briefing quotidien quand les
pas d'hier dépassent 1.5x la médiane perso.

**Architecture:** Réutilisation stricte du pattern E9.3 (`recovery_baselines.py` +
`briefing.py`). `steps` (déjà synchronisé dans `daily_metrics` par E2, rien à changer côté
sync) devient une 6ème métrique calculée par `compute_metric_baseline` (générique,
inchangée), stockée dans une nouvelle colonne jsonb `steps` de `recovery_baselines`.
`briefing.py` lit cette baseline et ajoute un `ReadinessFactor` optionnel `steps_high`.

**Tech Stack:** Python 3.12, FastAPI worker, Supabase Postgres (migration SQL), pytest.

## Global Constraints

- Seuil de déclenchement : `steps > baseline * 1.5` (spec §Décisions de design, point 3).
- Poids du facteur : `-5`, jamais davantage (spec §Décisions de design, point 4).
- Aucun changement du format JSON de sortie du briefing (`DailyBriefing`) — rétrocompat
  `/today` (spec §Décisions de design, point 5).
- Pas de garde anti-doublon avec `stress_avg`, pas de repli sur seuil absolu, pas
  d'affichage `/stats`, pas de sync `floorsAscended` (spec §Hors scope).
- Gate de confiance : facteur ne se déclenche que si la baseline `steps` a une confidence
  `high` ou `medium` (comme `stress`/`body_battery`, via `_gated_baseline`).
- Migration SQL nullable, pas de backfill (spec §Table recovery_baselines).

```python
def _score_steps(daily: dict[str, Any] | None, baseline: float | None) -> list[ReadinessFactor]:
    if not daily or not baseline or baseline <= 0:
        return []
    steps = daily.get("steps")
    if steps is None:
        return []
    if steps > baseline * 1.5:
        return [
            ReadinessFactor(
                "steps_high", -5, f"Beaucoup de pas hier ({steps} vs médiane {baseline:.0f})."
            )
        ]
    return []
```
